Система учета поступления и продаж товаров

Десктопное приложение для ведения учета поступления и продаж товаров. 
Позволяет управлять справочниками товаров и контрагентов, оформлять поставки и продажи, 
а также отслеживать остатки на складе.

## Стек технологий
Язык программирования: C#
Платформа: .NET Framework 4.7.2
UI: Windows Forms
База данных: MySQL
Доступ к данным: прямые SQL-запросы
Безопасность: Хеширование паролей (PBKDF2 через PasswordHasher)

## Функционал
Управление справочниками: товары, торговая наценка, поставщики, покупатели и т.д.
Учет операций: оформление прихода товара на склад и продаж.
Безопасность: пароли пользователей хранятся в БД в виде хешей.

## Установка и запуск

### Требования
Visual Studio 2022 (или 2019)
Установленный MAMP
Установленный MySQL-сервер (входит в MAMP)

### Шаги для запуска

Клонируйте репозиторий: git clone https://github.com/tatyana090975/Store.git

Импортируйте файл furniture_store.sql в phpMyAdmin. Это создаст базу данных и все 19 таблиц.

В файле DB укажите вашу строку подключения к БД (логин/пароль от локального сервера). 
Текущая строка "server=localhost;port=3306;username=root;password=root;database=furniture_store".

Откройте решение .sln в Visual Studio, соберите проект (Ctrl+Shift+B) и запустите (F5).

Для первого входа используйте логин: Admin, пароль: 111. 
(Права доступа еще не разделены и у всех пользователей они одинаковые).

### Описание бд
Список таблиц:
1. Пользователи (users).
2. Персоны (person).
3. Должности (position).
4. Работники (employe).
5. Формы собственности (ownership).
6. Цвета (color).
7. Материал (material).
8. Элементы (element).
9. Товар (product).
10. Таблица-связка товара/материала/элемента (product_material).
11. Доставка (delivery).
12. Наценка (tradeMarginTable).
13. Услуга (services).
14. Контрагенты (counteragent).
15. Поступление товара (supplierProducts).
16. Таблица поступления товара (supProdTable).
17. Продажа (saleProducts).
18. Таблица продажи (saleProdTable).
19. Продажа услуги (saleServices).

### Особенности
Обработчик события OKButton_Click в каждом классе наследнике ParentCardForm переопределяется 
таким образом, что кортежи данных для передачи в функцию формируются в обработчике и сохраняются 
в поле-список CardData класса. 

Список CardData хранит кортежи, состоящие из наименования столбца таблицы и данных из соответствующего 
поля карточки. 

На вход функции SaveCard подается наименование таблицы и одномерный массив данных типа 
params (string column, object value)[] data, получаемый из поля-списка CardData класса.

SQL-запрос формируется динамически и обрабатывает сохраняемые данные для любой таблицы 
базы данных. Одной функцией пользуются все классы карточек.
